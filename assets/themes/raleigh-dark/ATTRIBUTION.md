# Raleigh-Dark theme attribution

Nuxpad's Retro Dark theme derives its palette and selected control artwork from
the separate Gtk-Theme-Raleigh project:

https://github.com/thesquash/gtk-theme-raleigh

Gtk-Theme-Raleigh recreates the classic Raleigh GTK appearance. Nuxpad uses
selected Raleigh-Dark control assets and the Raleigh-derived palette alongside
its own Qt styling.

Only the Raleigh artwork that Nuxpad actually references is retained here.
Raleigh is not part of Chicago95 and is therefore stored as its own sibling
theme resource under `themes/raleigh-dark/`.
