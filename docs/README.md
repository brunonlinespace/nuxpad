# Nuxpad 2

**Friendly. Fast. Focused.**

Nuxpad 2 is a lightweight plain-text editor for Linux and Windows, built with Python and PyQt6 from one shared application source.

The canonical portable entrypoint is project-root `main.py`, which delegates to:

```text
nuxpad2/source/nuxpad.py
```

Nuxpad preserves its existing text-editing, search/replace, printing, encoding, line-ending, drag-and-drop, external-change protection, AppImage theme and cross-platform behavior.
