# Chicago95 theme attribution

Nuxpad's Retro Light theme is a PyQt6/Qt adaptation of the Chicago95 project:

https://github.com/grassmunk/chicago95

Chicago95 describes itself as an XFCE/Xubuntu Windows 95 total conversion and
states its licence as **GPL-3.0+/MIT**.

Credits retained from the supplied Chicago95 project:

- Grassmunk — 4/2016
- AdrianoML — 12/2016
- EMH-Mark-I — 4/2017

Only the Chicago95 GTK3 artwork and 16 px action icons that Nuxpad actually
references are retained in this source tree. They remain unmodified.

Nuxpad's `chicago95.qss` is a PyQt6/Qt adaptation written for this experiment;
it does not require Chicago95 to be installed on the host.

Raleigh is a separate upstream project and is stored separately under the
sibling `themes/raleigh-dark/` directory. It is not part of Chicago95.
