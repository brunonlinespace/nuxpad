# Nuxpad 2 source-portable format

The canonical Portable entrypoint is the project-root `main.py`.

Linux:

```bash
./nuxpad2/portable/run-nuxpad.sh
```

Windows CMD:

```text
nuxpad2\portable\run-nuxpad.cmd
```

Windows PowerShell:

```powershell
.\nuxpad2\portable\run-nuxpad.ps1
```

Requires host Python 3 and PyQt6. Source-portable runs use the host Qt theme.
